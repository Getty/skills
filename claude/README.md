# Claude skills

Working with Claude itself — spawning it, routing work to its models.

| Skill | Covers |
|---|---|
| [claude-headless](claude-headless/SKILL.md) | Spawning a headless Claude Code from a script or from inside a running session — `claude -p`, matching the parent's model, permissions without prompts, JSON output, resuming. |
| [model-routing](model-routing/SKILL.md) | Deciding which Claude model work runs on — the tier rubric for delegating tasks, splitting work so it routes cheap, and sizing agent roles when building a team. |
