# Change log

## 1.0.0 — 2026-10-13

Created from a design note on a production Moose task DSL. Reorganized into a compact
English skill, focused references, original runnable examples, negative tests,
manual agent evaluation cases, source provenance, and explicit validation limits.

Added a separate planning boundary, explicit ownership alternatives, inheritance and
cross-owner conflict policy, safe predicate contracts, real-versus-wrapped concurrency
explanations, non-mutating nullable schema unions, and resume/idempotency guidance.

No compatibility with the API of an existing DSL is claimed.
