## Changes and residual uncertainty

Record changed assumptions, stale sources, untested paths, exclusions from scope, residual risks, approved restrictions and expiry. An exception cannot waive law.

## Approval and deployment

Record the actual authority/approval reference, not a generated signature. Record deployment configuration verification, rollback readiness, and the event that triggers the next review. Keep sensitive evidence in restricted storage.
