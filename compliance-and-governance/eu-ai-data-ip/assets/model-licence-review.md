# Model and dependency licence review

Record the exact model/weights/code/data/adapter versions separately. For each, record licence text and hash, provider entity, commercial hosting, modification, training/distillation, redistribution, notices/source obligations, use restrictions, patent/termination clauses and downstream commitments. Add negotiated overrides and their scope.

Inspect actual build/distribution artefacts and operational routing. State whether the planned use is permitted, conditional, unknown or prohibited. Identify review triggers for a new model version, updated terms, changed customer population or new distribution channel.
