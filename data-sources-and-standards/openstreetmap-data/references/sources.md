# Primary sources and version notes

OSM documentation and service policies evolve. Follow the linked current documentation for executable options and endpoint use. OSM is a dataset with community conventions; do not describe every wiki page as a formal normative standard.

## Native model and formats

- [OSM elements](https://wiki.openstreetmap.org/wiki/Elements): nodes, ways, relations, and tags.
- [OSM file formats](https://wiki.openstreetmap.org/wiki/OSM_file_formats): snapshots, history, and change formats.
- [PBF format](https://wiki.openstreetmap.org/wiki/PBF_Format): binary representation and structure.
- [OsmChange](https://wiki.openstreetmap.org/wiki/OsmChange): change-document structure.
- [Planet replication diffs](https://wiki.openstreetmap.org/wiki/Planet.osm/diffs): feed concepts and state.
- [Osmium Tool manual](https://osmcode.org/osmium-tool/manual.html): mature inspection and processing operations.
- [osm2pgsql manual](https://osm2pgsql.org/doc/manual.html): an example of a database importer and dependency-aware updating.
- [Geofabrik extracts](https://download.geofabrik.de/): provider-specific regional files and associated documentation.

## Identity, services, and rights

- [wikidata tag](https://wiki.openstreetmap.org/wiki/Key:wikidata) and [operator:wikidata](https://wiki.openstreetmap.org/wiki/Key:operator:wikidata): different identity roles.
- [Nominatim API overview](https://nominatim.org/release-docs/latest/api/Overview/) and [reverse geocoding](https://nominatim.org/release-docs/latest/api/Reverse/): search behavior and reverse-geocoder limits.
- [Public Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/) and [standard tile usage policy](https://operations.osmfoundation.org/policies/tiles/): policies for those services.
- [Martin documentation](https://maplibre.org/martin/): tile serving.
- [PMTiles documentation](https://docs.protomaps.com/pmtiles/): prepared tile archives and range access.
- [OSRM project](https://project-osrm.org/): road routing software.
- [OpenStreetMap copyright and license information](https://www.openstreetmap.org/copyright): ODbL and attribution starting points.

The update-generation contract, matching workflow, and synthetic examples in this skill are application design guidance. They are not presented as additional requirements imposed by the OSM format.
