# Reusable planning and evidence assets

Use [intake](intake.md), [dependency decisions](library-decision.md), [implementation plans](implementation-plan.md), [compatibility matrix](compatibility-matrix.csv), and [validation records](validation-record.md) as project artifacts. Leave unexecuted checks marked Not run.

The [library catalog](library-catalog.json), [source registry](sources.json), [reference map](reference-map.json), and [claim matrix](claim-matrix.csv) are machine-readable routing/evidence data. They are not an instruction to install all libraries or load all references. Source-linked claims and engineering procedures still require installed-version verification.

[Agent evaluation prompts](agent-evaluations.md) provide adversarial task scenarios and a scoring rubric.

Use the [threat model](threat-model.md), [permission matrix](permission-matrix.csv), [IPC request schema](ipc-contract.schema.json), and [release checklist](release-checklist.md) for privileged/runtime work.
