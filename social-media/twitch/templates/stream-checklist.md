# Stream Checklist

## T−30 min — machine

- [ ] Reboot done, updates **not** pending (no surprise restart mid-stream)
- [ ] Notifications off (OS focus mode, Discord, mail, phone)
- [ ] Browser: streaming profile only — no personal tabs, no password manager unlocked
- [ ] Secrets out of the captured window: `.env`, tokens, customer data, invoices
- [ ] Correct OBS scene collection and profile loaded

## T−15 min — signal

- [ ] Scene `5 WAITING` active, music audible in monitor
- [ ] `MAIN WINDOW` matched, not black — check in `1 MAIN` preview
- [ ] Mic meter moves when you speak; desktop meter moves with app audio
- [ ] Voice peaks ≈ −6 dB, desktop ≈ −18 dB
- [ ] Camera framed, lit, in focus; vertical safe area checked if using Dual Format
- [ ] Headphones on, monitoring verified once

## T−5 min — metadata

- [ ] Title: specific and searchable, not a mood
- [ ] Category matches what will actually be on screen
- [ ] Tags set, including language
- [ ] Content Classification Labels honest
- [ ] **DACH:** if content is USK 16+/18+, is the slot legal? (22:00 / 23:00 — see
      `references/germany-youth-protection.md`)
- [ ] **DACH:** sponsored today? "Werbung" on screen + in title + spoken at segment start
- [ ] Chat modes set (followers-only default), Shield Mode preset ready and bound
- [ ] Mods briefed on anything unusual today

## Go live

- [ ] Start stream → confirm "Live" → check Twitch Inspector shows a clean bitrate
- [ ] 2–5 min waiting scene → switch to `4 CAM`
- [ ] Say what today is in the first 30 seconds

## After

- [ ] Raid out
- [ ] Stream summary: numbers into notes (see `references/analytics.md`)
- [ ] Pick and publish one clip
- [ ] Local recording saved and backed up
- [ ] Anything that broke → fix before next stream, or it will break again
