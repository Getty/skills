# Scope and attribution

This package contains original explanatory material and demonstration implementations.
It does not bundle the Gearmand source tree, third-party language bindings, credentials,
container images or fonts. Upstream projects retain their own licenses and trademarks.
Source URLs and the scope of actual review are recorded in [sources](references/sources.md).
No upstream endorsement or production certification is implied.

The optional readme is for human navigation. Essential agent knowledge is in SKILL.md
and its reference graph. Operational templates remain unapplied; installs, submissions,
service changes and deployments require deliberate operator action.
