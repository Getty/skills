# Primary-source register

**Snapshot: 2026-10-10. 103 distinct primary-source entries.**

Each topical reference links its immediate sources. This register identifies the authority and date so a later agent can recheck the claim rather than preserve an outdated default. Documents were consulted as HTML; no third-party article substitutes for a standard or vendor policy.

A review date is not an effective date, a deployment test, a claim that every linked subpage was read, or a guarantee of future URL availability. Living documentation can describe a newer release than the executable lab; the lab records its actual builds. The [claim ledger](CLAIMS.md) connects critical claims with documentary and experimental evidence. The [JSON register](sources.json) supports maintenance tooling.
