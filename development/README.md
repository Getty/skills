# Development skills

Engineering practice — workflows and disciplines that apply regardless of
language or domain. Where a skill documents a tool, the tool-specific
groups (perl, system-and-network-administration) own it; this group covers
how to *do the work*, not which tool to reach for.

| Skill | Covers |
|---|---|
| [feedback-loop-debugging](feedback-loop-debugging/SKILL.md) | Disciplined debugging loop for hard bugs and performance regressions — build a deterministic feedback loop first, then reproduce, hypothesise, instrument, fix, regression-test, post-mortem. |
